# Freshly

Трекер сроков годности продуктов для сокращения пищевых отходов дома.
Notar Academy Selection, тема «Food Waste at Home».

## Возможности
- Быстрое добавление: срок годности подставляется по названию («молоко» → 7 дней), чипы +3/+7/+14 дней
- Статусы «Свежее», «Скоро испортится», «Испорчено» и полоса свежести на каждой карточке
- Фильтры со счётчиками, сортировка по сроку, удаление с отменой
- Данные сохраняются между сессиями

## Стек
Next.js 15 (App Router), TypeScript strict, Tailwind v4, Zod, lucide-react, Geist.

## Структура
- `lib/freshness.ts` — чистая логика статусов и сроков
- `lib/schema.ts` — Zod-схемы и типы
- `lib/storage.ts` — репозиторий хранения (сейчас localStorage, заменяем на API без правок UI)
- `hooks/useProducts.ts` — состояние и персистентность
- `components/tracker/*` — UI трекера

## Запуск
```bash
npm install
npm run dev
```
Открыть http://localhost:3000

## Деплой
Импортировать репозиторий на vercel.com/new, настройки по умолчанию.
